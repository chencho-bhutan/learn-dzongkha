Formation of Words — མིང་ཚིག་བཟོ་ནི།

Like English, Dzongkha words are built by combining smaller pieces. But unlike English, word formation follows strict, defined rules about which letters are allowed to combine with which.

The three combination rules

1. Ngonjug letters are picky. Each of the 5 Ngonjug (prefix) letters can only attach to a specific, predefined set of Mingzhi letters — not any Mingzhi at random.

2. Jejug letters are flexible. All 10 Jejug (suffix) letters can follow any Mingzhi letter, single or compounded.

3. Yangjug ས has one condition. It can only appear after a Jejug letter that is one of: ག་ང་བ་མ.

With these rules in place, every Dzongkha word falls into one of several recognizable composition patterns.

Pattern 1: Mingzhi alone (single-letter words)

ཁmouth
ངI
ཉfish
ཟeat
རgoat
ཤmeat
སsoil / land

Pattern 2: Compounded letter alone (Gochen or Dogchen)

ཁྲpattern
ལྔfive

Pattern 3: Compounded letter + vowel

རྡོstone
གྲུboat

Pattern 4: Compounded letter with both Gochen and Dogchen

སྤྱmonkey

Pattern 5: Gochen + Dogchen compound + vowel

སྐྱོsad

Pattern 6: Ngonjug + Mingzhi

མནོthink
འགྱོgo
བརྐོdig
བརྒྱhundred

Pattern 7: Ngonjug + Mingzhi + Jejug

མདའarrow
མཐུནfriendly
འཕྱདmeet
འཁྲུལsentimental
བསྐོརsurround
བསྐྲདerase
བསྒྱུརaccumulate

Pattern 8: Mingzhi + Jejug

དངand
ཆོསreligion
སྲསprince
སྟགtiger
རྒྱལwin
སྲོགlife
སྒུགwait
སྒྲུབpractice

Pattern 9: Mingzhi + Jejug + Yangjug

ཆགསland
གྲངསcount
སྐབསduring
སོགསetc.
ཕྱུགསcattle
རྟོགསrealize
སྐྱོབསprotect

Pattern 10: Ngonjug + Mingzhi + Jejug + Yangjug

The fullest structure — all four positional categories present at once.

བསགསsaved
མཆོངསjumped
འཁྲུངསborn
བསྒྲུབསpracticed

Why this matters

What looks, at first glance, like unpredictable clusters of stacked letters is actually a small, closed set of patterns. Once you can recognize which pattern a word follows, reading unfamiliar words stops being guesswork and starts being pattern recognition.
